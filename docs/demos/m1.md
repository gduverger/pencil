# M1 demo — engine core

Runs the engine on the fixture deal from the command line and shows the funding schedule.

```bash
pnpm install --frozen-lockfile
pnpm --filter @pencil/engine test
```

Expected: 77 tests pass (7.3 program, 7.4 costs and distributions, 7.5 events, 7.6 funding order and
fixed point, validation, paths, schema catalog, invariants 1, 2, 5 and 8, the 50 ms budget), with
line coverage above 95%.

To see numbers, run a one-off script from the engine package:

```bash
cd packages/engine
cat > /tmp/m1-demo.ts <<'TS'
import { run } from './src/index';
import { fixtureDeal } from './test/fixtures';
const out = run(fixtureDeal());
console.log('TPC', out.totals.tpc.toFixed(0), 'iterations', out.diagnostics.iterations);
console.log('equity', out.totals.equity.toFixed(0), 'loan', out.totals.constructionLoan.toFixed(0), 'interest', out.totals.capitalizedInterest.toFixed(0));
for (const m of out.months.slice(0, 45)) console.log(m.t, m.phase, m.costTotal.toFixed(0), 'eq', (m.equityIn.gp + m.equityIn.lp).toFixed(0), 'draw', m.loanDraw.toFixed(0), 'bal', m.loanBalance.toFixed(0));
TS
cp /tmp/m1-demo.ts ./m1-demo.ts && ../../apps/cli/node_modules/.bin/tsx m1-demo.ts; rm m1-demo.ts
```

The schedule shows equity funding months 0 onward, the first construction-loan draw once equity is
exhausted, interest capitalized monthly on the prior balance, and the balance at month 42 (R)
equal to draws plus interest.
