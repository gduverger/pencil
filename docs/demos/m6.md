# M6 demo — results, scenarios and sensitivities

```bash
pnpm --filter @pencil/web build
cd apps/web
PENCIL_DEV_AUTH=1 AUTH_SECRET=dev DATABASE_URL=pglite://./.data/demo pnpm start -p 3000
```

Sign in, open a deal (or create one from `120 Highland Avenue, Needham, MA 02494`) and click the
**Results** tab:

1. The headline tiles show Likely with Best and Worst beneath; the Returns section lists every
   7.11 metric. The status reads *Live · rev N*: the engine runs in the browser.
2. Change *Hard cost per gross SF* in the **Quick inputs** panel and press Enter: every tile,
   table and flag updates immediately (the e2e test asserts under 200 ms) and the change autosaves.
3. Choose **Worst** in the scenario selector and change the exit cap: the field is marked
   *override* and unedited fields keep following Likely. Tick **Compare all three** to see the three
   scenarios side by side on any section (Returns, Sources & uses, Capital budget, Annual cash
   flow, Sale analysis).
4. Under **Sensitivities**, run *Exit cap rate × rent growth*: a 9 × 5 heat-shaded grid appears
   with the likely case outlined, saved with the deal. Change any input: the grid is marked
   *stale*; *Re-run* refreshes it. A custom grid takes any two numeric inputs and value lists.
5. Click *explain* on a headline tile: the engine's derivation trace (formula and operands).

pnpm --filter @pencil/web test:e2e
