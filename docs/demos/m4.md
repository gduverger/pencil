# M4 demo — package pages, PDF and Excel

```bash
pnpm install --frozen-lockfile
pnpm test                                   # includes the PDF timing test and the XLSX assertions
pnpm --filter @pencil/render test:snapshots # nine page snapshots plus a phone-width check
cd apps/cli
node bin/pencil.js run examples/needham-60.json --out /tmp/pencil-out --pdf --xlsx
```

`/tmp/pencil-out` then holds `package.html` (the nine pages rendered from the shared React
components), `needham-60-example-deal-likely-2026-11-04.pdf` (headless Chromium, Letter, two
landscape pages) and the `.xlsx` workbook (seven sheets, SUM formulas). Rendering the PDF takes
about a second after the browser is up; the whole command runs in under three seconds.

The fixture deal's PDF pages are in this directory as `page-01.png` … `page-11.png`
(the register flows over three pages). They were reviewed by eye on 2026-11-04:

| 8–10 | Assumptions register by section with scenario overrides | Dates no longer wrap after widening the column |
| 11 | Appendix: amortization by year and the methodology note | Landscape |

To open the Excel file and check the formulas without Excel:

```bash
cd packages/exports && pnpm test   # loads the workbook with exceljs and asserts SUM formulas and formats
```
