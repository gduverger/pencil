# M5 demo — deals and inputs

```bash
pnpm install --frozen-lockfile
pnpm --filter @pencil/web build
cd apps/web
PENCIL_DEV_AUTH=1 AUTH_SECRET=dev DATABASE_URL=pglite://./.data/demo pnpm start -p 3000
```

Open http://127.0.0.1:3000, sign in with any email (development sign-in, no mail is sent), then:

1. **New from address** → `120 Highland Avenue, Needham, MA 02494`, 60 units, land $3,000,000 →
   *Create deal*. The Setup tab shows the town (Needham, inner-suburbs cluster), the MBTA
   Communities note and that parcel data is not loaded in this environment (every parcel fact is
   `unknown`).
2. The **Inputs** tab opens in *Tonight* mode with the twelve starred inputs. Stabilized taxes are
   defaulted from the town rate (source `parcel data`); everything else is a schema default with
   source `unknown` until the benchmark seed is filled in.
3. Change hard cost to 320 and add a note; the status shows *Saved · rev N* after each change.
   Click *history* on the row: every change is listed with its prior value, source and note.
4. Click *elaborate* on hard cost, add *Sitework 2,000,000*: a *Remainder* child appears so the
   total does not jump; add *Structure 10,000,000*; the parent shows the derived $/SF read-only.
5. Add an inflow event (*Sell relocated house*, month 24, 400,000).
6. In *All inputs*, turn **Commercial space** on: its inputs appear; set gross SF; turn it off:
   the rows disappear and the value is kept for next time.
7. Open the same deal in a second tab, change a value in the first, then in the second: the
   second shows a revision conflict banner instead of overwriting.
