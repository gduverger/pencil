# M7 demo — package, versions and sharing

```bash
pnpm --filter @pencil/web build
cd apps/web
PENCIL_DEV_AUTH=1 AUTH_SECRET=dev DATABASE_URL=pglite://./.data/demo pnpm start -p 3000
```

Open a deal and click **Package**:

1. Toggle pages, pick the scenario for the detail pages, write a cover note and a narrative; the
   live preview below renders the same components as the PDF.
2. **Export PDF**: a Version is created (immutable inputs, switches, events, scenarios, engine
   outputs, sensitivities and settings, with the engine version) and the PDF is rendered by
   Chromium from the token-protected package route `/packages/<versionId>`; the message carries a
   signed download link. **Export Excel** creates Version 2 with the workbook.
3. **Share** on a Version creates a read-only link (`/share/<token>`, 32 random bytes) with an
   optional expiry. Open it in a private window: no sign-in, the package pages, download buttons
   for both files, readable at phone width.
4. **Revoke** a link: it returns 404 from then on. Old links keep showing their own Version after
   further exports.
5. With two Versions, **Diff versions** lists every changed input (path, old, new, note, who,
   when) and the changed headline metrics.
6. Clone from the deal list; owners can mark a deal as a template and create new deals from it.

Headless: `pnpm --filter @pencil/web test:e2e` (step 9, share and revoke, phone width).

Production: set `PENCIL_RENDER_URL` and `RENDER_TOKEN` to use the render service, `S3_BUCKET`
(`S3_ENDPOINT`, `S3_REGION`) for file storage, and `PENCIL_BASE_URL` for links.
