# M9 demo — assistant

```bash
pnpm --filter @pencil/assistant test   # recorded-response tests: intake fills a deal, post-check rejects and regenerates
```

With Claude (set `ANTHROPIC_API_KEY`; model `claude-opus-5-5` by default, `PENCIL_ASSISTANT_MODEL`
to change it) or with the scripted provider for a demo without a key (`PENCIL_ASSISTANT_FAKE=1`):

```bash
pnpm --filter @pencil/web build
cd apps/web
PENCIL_DEV_AUTH=1 AUTH_SECRET=dev DATABASE_URL=pglite://./.data/demo PENCIL_SEED_BENCHMARKS=e2e/fixtures/benchmarks-e2e.csv PENCIL_ASSISTANT_FAKE=1 pnpm start -p 3000
```

1. **Guided intake** (Setup and Inputs): type "72 units, wood frame, land at $2,500,000, GC says
   $335 per SF". The assistant replies and lists proposed inputs with source and note; nothing is
   written until you press *Apply*. Applied values carry the normal metadata and a note
   "confirmed from the assistant"; the transcript is stored with the deal.
2. **Explain this number** (Results → *explain* on a tile → *Explain in words*): two to four
   sentences built from the engine's trace, labeled *Drafted by the assistant*. Any number absent
   from the trace is rejected, the model is asked once more, and a remaining mismatch is shown with
   a warning.
3. **Reviewer notes** (Results): each engine or benchmark flag as one sentence with the comparison
   stated ("… of $500.00 is above the $280.00–$360.00 range …"); deterministic sentences are used
   when the assistant is not configured.
4. **Draft narrative** (Package): a ~120-word paragraph from the register and the headline
   metrics that states ranges; it is labeled *drafted by the assistant* until you edit it.

Budgets: `PENCIL_ASSISTANT_MONTHLY_TOKENS` (default 2,000,000) and `PENCIL_ASSISTANT_MONTHLY_REQUESTS`
(default 2,000) per organization per month; usage is recorded in `assistant_usage`.

Headless: `pnpm --filter @pencil/web test:e2e` (`e2e/assistant.spec.ts`).
