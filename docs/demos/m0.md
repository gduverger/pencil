# M0 demo — scaffold

Verifies the M0 acceptance criteria on a clean clone: `pnpm test` and `pnpm lint` pass.

```bash
git clone https://github.com/gduverger/pencil.git
cd pencil
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
```

Expected: every workspace package lints and typechecks, and each package's smoke test passes.
The repository layout matches `docs/SPEC.md` section 11.1:

```
apps/web  apps/render  apps/cli
packages/engine  packages/package-pages  packages/benchmarks  packages/parcels
packages/assistant  packages/db  packages/exports
reference/  docs/  scripts/
```
