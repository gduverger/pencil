# M8 demo — benchmarks and parcels

```bash
pnpm --filter @pencil/db test          # contributions are anonymized; the nightly recompute needs ≥5 deals from ≥3 orgs
pnpm --filter @pencil/benchmarks test  # seed template, resolution by segment, flags, percentiles
pnpm --filter @pencil/parcels test     # town table, address parsing, parcel-lookup stub
```

With a seeded benchmark (the end-to-end fixture `apps/web/e2e/fixtures/benchmarks-e2e.csv` or
Mark's filled `packages/benchmarks/seed/benchmarks.csv`):

```bash
pnpm --filter @pencil/web build
cd apps/web
PENCIL_DEV_AUTH=1 AUTH_SECRET=dev DATABASE_URL=pglite://./.data/demo PENCIL_SEED_BENCHMARKS=e2e/fixtures/benchmarks-e2e.csv pnpm start -p 3000
```

1. New deal from `55 Chapel Street, Needham, MA`: Setup shows the town (Needham) and cluster
   (inner-suburbs); stabilized taxes default from the town's residential rate with the
   `parcel data` source and a note naming the rate and fiscal year.
2. On Inputs, hard cost per gross SF is pre-filled with the benchmark mid (320) and source
   `benchmark`; the range $280.00 – $360.00 sits beside the field. Type 500: the *outside range*
   flag appears, the header counts it, Results still run (flags never block).
3. The Package preview's assumptions register names the range in the flag; the Returns page counts
   inputs outside their benchmark range.
4. Opt in on Settings (*Contribute anonymized values*); every export then records the deal's
   seed-list values with segment keys and the export month only (`contributions` table).
5. The nightly job: `pnpm --filter @pencil/web nightly` locally, or `POST /api/jobs/benchmarks`
   with the `JOBS_SECRET` (Vercel cron). It writes `contrib:` benchmark rows as 25th/50th/75th
   percentiles once a segment has five contributions from three organizations.

Headless: `pnpm --filter @pencil/web test:e2e` (`e2e/benchmarks.spec.ts`).
