# M3 demo — engine analysis and the CLI

The engine is usable from the command line before any screen exists.

```bash
pnpm install --frozen-lockfile
pnpm --filter @pencil/engine test
cd apps/cli
node bin/pencil.js run examples/needham-60.json --out /tmp/pencil-out
```

Expected console output (numbers from the example deal):

```
Needham 60 — example deal — engine 0.1.0
  Project IRR   likely 11.2%  best 16.4%  worst 6.7%
  LP IRR        likely 10.6%  best 15.0%  worst 6.7%
  Yield on cost likely 6.0%  best 7.0%  worst 5.2%
  Total cost    likely 29,006,938
  Residual land value at 7.0% yield on cost: 0 (0 per unit) (target not reachable even with free land)
  flag [worst] refinance-shortfall: ...
  wrote /tmp/pencil-out/outputs.json, summary.json, package.html
```

Then open `/tmp/pencil-out/package.html` in a browser: summary and returns for the three
scenarios, sources and uses, capital budget, annual cash flow, sale analysis, flags and the
assumptions register with scenario overrides.

Options: `--scenarios scenarios.json` supplies Best/Worst override maps
(`{ "best": { "exit.exitCapRatePct": 0.05 }, "worst": { ... } }`); `--no-rlv` skips the residual
land value search.

## Golden tests

```bash
python3 scripts/extract-golden.py reference/ packages/engine/test/golden/
```

With the reference workbooks absent the script reports each one as skipped; the golden test in
`packages/engine/test/golden.test.ts` passes with a console note and will assert the 12.3
tolerances as soon as extracted JSON files and adapters exist.
